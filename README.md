# Cublaster

A 3D browser-based game where you control a geometric shape and blast enemies off the platform. Built for the [Pirate Software Game Jam 15](https://itch.io/jam/pirate15/rate/2866715) (July 17-31, 2024).

## 🎮 Play Now

**[Play Cublaster on itch.io](https://badmagick.itch.io/cublaster)**

## About

Cublaster was created in two weeks for Pirate Software Game Jam 15. The theme was **"Alchemy and Shadows"**.

You and your enemies are simple geometric shapes battling on a platform. Use your abilities to knock enemies off the edge and defend your objective.

This jam was also our first introduction to Three.js, so we were learning as we went. While we weren't able to fully realize our vision within the timeframe, the core shooting and knockback mechanics are functional. Our original concept included enemies returning as shadows to aid you after being knocked off, a secondary ability for enhanced knockback, and collectible alchemical objects to progress through levels.

## Controls

- **WASD / Arrow Keys** - Move
- **Mouse** - Aim
- **Left Click** - Shoot

## Built With

- [Three.js](https://threejs.org/) - 3D graphics
- [Cannon-es](https://pmndrs.github.io/cannon-es/) - Physics engine
